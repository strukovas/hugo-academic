# Historical Hugo source

The maintained source for Sofia Strukova's website has moved to:

**https://github.com/strukovas/strukovas.github.io/tree/main/site**

Edit Markdown and configuration there. The website repository now builds and publishes through GitHub Actions on pushes to `main`.

This repository is retained as a historical copy. Its content predates several changes to the live website; its `public` submodule and Windows Hugo binary are no longer used for publishing. Do not use it to rebuild or overwrite the live site.

The migration preserved the current biography, affiliation, experience, news and all 16 publication records, corrected DOI URL handling, and removed unused starter pages. See the maintained repository's README for preview, editing and publishing instructions.
